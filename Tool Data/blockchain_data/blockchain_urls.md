# Major Blockchain Network URLs & Endpoints

A comprehensive reference file listing official websites, public RPC endpoints, and block explorers for major blockchain networks.

## 1. Bitcoin (BTC)
* **Official Website:** [Bitcoin.org](https://bitcoin.org)
* **Block Explorers:**
  * [Mempool.space](https://mempool.space)
  * [Blockchain.com Explorer](https://www.blockchain.com/en/explorer)
  * [Blockchair Bitcoin](https://blockchair.com/bitcoin)

## 2. Ethereum (ETH)
* **Official Website:** [Ethereum.org](https://ethereum.org)
* **Public RPC Endpoints:**
  * `https://cloudflare-eth.com`
  * `https://eth.llamarpc.com`
* **Block Explorers:**
  * [Etherscan](https://etherscan.io)
  * [Blockscout](https://blockscout.com)

## 3. Solana (SOL)
* **Official Website:** [Solana.com](https://solana.com)
* **Public RPC Endpoints:**
  * `https://api.mainnet-beta.solana.com`
* **Block Explorers:**
  * [Solscan](https://solscan.io)
  * [Solana Explorer](https://explorer.solana.com)

## 4. BNB Chain (BNB)
* **Official Website:** [BNBChain.org](https://www.bnbchain.org)
* **Public RPC Endpoints:**
  * `https://bsc-dataseed.binance.org/`
  * `https://binance.llamarpc.com`
* **Block Explorers:**
  * [BscScan](https://bscscan.com)

## 5. Polygon (POL / MATIC)
* **Official Website:** [Polygon.technology](https://polygon.technology)

  * `https://polygon-rpc.com`

  * [Polygonscan](https://polygonscan.com)

## 6. Base (Layer 2)
